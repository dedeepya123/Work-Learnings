Loads the quantized embedding layer from the model checkpoint.

1. Creates a _Gemma4QuantizableEmbedding module using LLM configuration.
2. Loads embedding weights from model.safetensors.
3. Loads embedding quantization scales (if available).
4. Copies the weights and scales into the embedding module.
5. Sets the module to evaluation mode.
6. Returns the initialized embedding layer.
