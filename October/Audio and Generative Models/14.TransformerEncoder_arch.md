# TransformerEncoder Architecture

## Why This Matters

Before understanding:

```text
TextEncoder
SpeakerEncoder
AudioContextEncoder
```

we need to understand the common building block they use:

```text
TransformerEncoder
```

All three encoders are built using stacks of:

```text
TransformerEncoderLayer
```

Conceptually:

```text
Input Features
        ↓
Transformer Layer
        ↓
Transformer Layer
        ↓
Transformer Layer
        ↓
Output Features
```

---

## High-Level Architecture

A single TransformerEncoderLayer follows:

```text
Input
  ↓

RMSNorm
  ↓

Multi-Head Attention
  ↓

RMSNorm
  ↓

Residual Add

  ↓

RMSNorm
  ↓

Feed Forward Network
  ↓

RMSNorm
  ↓

Residual Add

  ↓

Output
```

This structure is repeated multiple times.

---

## TransformerEncoder

The encoder itself is simple.

```python
self.layers = nn.ModuleList([
    TransformerEncoderLayer(...)
    for _ in range(num_layers)
])
```

Forward pass:

```python
for layer in self.layers:
    x = layer(x, mask=mask)
```

Conceptually:

```text
x
 ↓

Layer 1
 ↓

Layer 2
 ↓

Layer 3
 ↓

...
 ↓

Layer N
 ↓

Output
```

---

# TransformerEncoderLayer

Each layer contains two major blocks.

```text
Attention Block

Feed Forward Block
```

This should feel very similar to:

```text
BERT
GPT
ViT
```

style transformer layers.

---

# Part 1: Attention Block

## Step 1: Pre-Normalization

```python
h = self.pre_attn_ln(x)
```

Uses:

```python
RMSNorm
```

instead of:

```python
LayerNorm
```

Conceptually:

```text
Input
 ↓
Normalize
 ↓
Attention
```

---

## What Is RMSNorm?

Most transformer papers use:

```text
LayerNorm
```

VoiceDM uses:

```text
RMSNorm
```

Benefits:

```text
Lower Compute
Simpler Mathematics
Common in modern LLMs
```

Examples:

```text
LLaMA
Mistral
Gemma
```

also rely heavily on RMSNorm.

---

## Step 2: Multi-Head Attention

```python
h = self.attn(h, h, h, mask=mask)
```

This is standard self-attention.

Queries:

```text
h
```

Keys:

```text
h
```

Values:

```text
h
```

So:

```text
Self Attention
```

---

### Configuration

```python
use_rope=True
```

Meaning:

```text
Rotary Position Embeddings
```

are applied.

---

### RoPE

Instead of learned positional embeddings:

```text
Position 1
Position 2
Position 3
```

VoiceDM uses:

```text
RoPE
```

which injects position information directly into attention calculations.

This is the same family of technique used in:

```text
LLaMA
Mistral
Qwen
```

---

### Number Of Attention Heads

Depends on the encoder.

Examples:

```text
TextEncoder
6 Heads
```

```text
SpeakerEncoder
8 Heads
```

```text
AudioContextEncoder
8 Heads
```

# Part 2: Feed Forward Network

After attention:

```text
FFN Block
```

runs.

---

## Step 1: RMSNorm

```python
h = self.pre_ffn_ln(x)
```

Normalize before FFN.

---

## Step 2: Feed Forward Expansion

```python
Linear(
    model_dims,
    hidden_dims
)
```

Example:

```text
768
 ↓
3072
```

for the text encoder.

---

## Step 3: GELU Activation

```python
GELU(approximate="tanh")
```

This is the same activation commonly used in:

```text
BERT
GPT
ViT
```

---

## Step 4: Projection Back

```python
Linear(
    hidden_dims,
    model_dims
)
```

Example:

```text
3072
 ↓
768
```

---

## FFN Flow

Conceptually:

```text
Input
 ↓

Linear Expansion

 ↓

GELU

 ↓

Linear Projection

 ↓

Output
```

---

## Step 5: Residual Connection

Again:

```python
x = residual + ffn_output
```

Conceptually:

```text

     +
FFN Result
     ↓
Output
```

# Primer Hybrid Style

Notice something unusual.

The layer uses:

```text
Pre-Attention RMSNorm

Post-Attention RMSNorm

Pre-FFN RMSNorm

Post-FFN RMSNorm
```

This is described as:

```text
primer_hybrid
```

style normalization.

Conceptually:

```text
Normalize Before Block

and

Normalize After Block
```

rather than using only one normalization location.

# VoiceDM Usage

This encoder stack is reused by:

```text
TextEncoder

SpeakerEncoder

AudioContextEncoder
```

Each provides different inputs but relies on the same transformer architecture internally.

---

# Key Takeaways

- VoiceDM uses a standard transformer encoder architecture.
- Each layer contains a Self-Attention block and an FFN block.
- RMSNorm is used instead of LayerNorm.
- RoPE provides positional information.
- Residual connections are used after attention and FFN blocks.
- GELU is the activation function.
- The architecture follows a Primer-Hybrid normalization strategy.
- TextEncoder, SpeakerEncoder, and AudioContextEncoder all reuse this transformer stack.
