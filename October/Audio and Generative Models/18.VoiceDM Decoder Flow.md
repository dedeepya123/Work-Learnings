# VoiceDM Decoder Flow

## Purpose

The top-level decoder entry point is:

```python
voicedm_decode(...)
```

Its responsibility is to:

```text
Load Decoder Model
        ↓
Generate Diffusion Noise
        ↓
Run Diffusion Decoder
        ↓
Generate Audio Features
```

Unlike the encoder, the decoder is responsible for actual generation.

---

## Position Inside VoiceDM Pipeline

End-to-end:

```text
Input Text
      ↓
VoiceDM Encoder
      ↓
cond
cond_paddings
      ↓
VoiceDM Decoder
      ↓
Audio Features [B,100,96]
      ↓
SoundStream Decoder
      ↓
Waveform Audio
```

---

## Inputs

### Conditioning Tensor

Produced by:

```text
VoiceDMEncoder
```

Input:

```python
cond_inputs
```

Shape:

```python
[B,320,768]
```

Represents:

```text
Speaker Information
+
Audio Context Information
+
Text Information
```

---

### Conditioning Mask

Input:

```python
cond_inputs_paddings
```

Shape:

```python
[B,320]
```

Purpose:

```text
Identify active vs padded conditioning tokens.
```

---

### Noise

Optional:

```python
eps
```

Shape:

```python
[8,1,100,96]
```

Represents:

```text
Initial diffusion noise
```

If not supplied, noise is generated automatically.

---

# Step 1 - Instantiate VoiceDM Decoder

First:

```python
model = _instantiate_voicedm_decoder(...)
```

is executed.

Responsibility:

```text
Create Architecture
        ↓
Load Checkpoint
        ↓
Apply Optional Quantization
        ↓
Return Model
```

This mirrors the encoder flow.

---

## Important Observation

The actual neural network is:

```python
VoiceDMDecoder(nn.Module)
```

not:

```python
voicedm_decode(...)
```

Just like the encoder case.

For quantization workflows such as AIMET:

```text
VoiceDMDecoder
```

is the primary model object.

---

# Step 2 - Generate Diffusion Noise

If no noise is supplied:

```python
eps = _epsilon(seed=seed)
```

is called.

---

Conceptually:

```text
Random Noise
      ↓
Diffusion Process
      ↓
Audio Representation
```

This is the starting point for generation.

---

## Noise Shape

Generated noise:

```python
[8,1,100,96]
```

Interpretation:

```text
8 Diffusion Steps

Batch Size = 1

100 Audio Positions

96 Feature Dimensions
```

---

## Why Noise?

Diffusion models generate content by:

```text
Starting From Noise
        ↓
Repeated Denoising
        ↓
Meaningful Output
```

Similar to:

```text
Stable Diffusion

Imagen

AudioLDM

VoiceDM
```

---

# Step 3 - Decoder Forward Pass

The actual decoder execution:

```python
model(
    cond=cond_inputs,
    cond_paddings=cond_inputs_paddings,
    eps=eps
)
```

---

Inputs:

```text
Conditioning Tensor
        +
Conditioning Mask
        +
Noise
```

---

Conceptually:

```text
Noise
      +
Conditioning
      ↓
DiT
      ↓
8-Step Diffusion
      ↓
Audio Features
```

---

# Output

The decoder returns:

```python
pred_x0
```

Shape:

```python
[B,100,96]
```

---

## What Is pred_x0?

This is the output of the diffusion process.

It represents:

```text
Generated Audio Features
```

Important:

```text
This is NOT waveform audio.
```

It is a learned audio representation.

---

## Why [100,96]?

We previously saw:

```python
speaker_prompt_array
=
[B,83,96]

audio_context_array
=
[B,100,96]
```

VoiceDM's learned audio representation space uses:

```text
96-dimensional feature vectors
```

for each time position.

The diffusion model generates these features directly.

---

# Decoder Responsibilities

The decoder is responsible for:

```text
Noise
      ↓
Audio Features
```

It is NOT responsible for:

```text
Waveform Reconstruction
```

That responsibility belongs to:

```text
SoundStream Decoder
```

# Key Takeaways

- `voicedm_decode()` is the decoder orchestration wrapper.
- It loads the actual VoiceDMDecoder model.
- It generates diffusion noise if none is provided.
- VoiceDMDecoder consumes conditioning information and noise.
- The decoder performs generation through diffusion.
- The output is a learned audio representation of shape `[B,100,96]`.
- No waveform audio is produced here.
- Waveform reconstruction happens later in the SoundStream decoder.
- For AIMET workflows, the relevant model object is `VoiceDMDecoder(nn.Module)`.
