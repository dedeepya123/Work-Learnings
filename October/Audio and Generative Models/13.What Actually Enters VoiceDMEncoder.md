## What Actually Enters VoiceDMEncoder?

Despite the name "Encoder", the model does not receive embeddings for all inputs.

### Text Path

Input:

```python
[B,256]
```

contains token IDs.

These are converted into embeddings inside the TextEncoder.

```text
Token IDs
 ↓
TextEncoder
 ↓
Text Embeddings
```

### Speaker Path

Input:

```python
[B,83,96]
```

contains speaker audio features produced by the SoundStream encoder.

```text
Speaker Audio
 ↓
SoundStream Encoder
 ↓
Speaker Features
 ↓
SpeakerEncoder
```

### Audio Context Path

Input:

```python
[B,100,96]
```

contains audio-context features.

```text
Context Audio
 ↓
SoundStream Encoder
 ↓
Context Features
 ↓
AudioContextEncoder
```

The VoiceDMEncoder therefore receives:

```text
Token IDs
+
Speaker Audio Features
+
Audio Context Features
```

and transforms them into a unified conditioning representation (`cond`) used by the diffusion decoder.
