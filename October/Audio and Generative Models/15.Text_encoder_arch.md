# TextEncoder Architecture

## Purpose

The TextEncoder converts tokenized text into contextualized text representations that can be used by the rest of VoiceDM.

Conceptually:

```text
Token IDs
     ↓
Embedding Layer
     ↓
Transformer Encoder
     ↓
Text Features
```

The goal is to answer:

```text
What should be spoken?
```

before the diffusion model begins generation.

---

## Position Inside VoiceDM

The TextEncoder is the first component inside:

```text
VoiceDMEncoder
```

Flow:

```text
Tokenized Text
      ↓
TextEncoder
      ↓
Text Embeddings
      ↓
MetaEncoder
```

---

Input tensor:

```python
[B, T]
```


Shape transformation:

```python
[B,T]
```

```python

```

---

## Why Embeddings?

Neural networks cannot directly understand integer token IDs.

For example:

```text
Token 5
```

is not inherently smaller or larger than:

```text
Token 100
```

The embedding layer converts token IDs into dense vectors that can capture semantic relationships.

Conceptually:

```text
Token IDs
      ↓
Embeddings
      ↓
Meaningful Vector Space
```

---

## Step 2 - Embedding Scaling

After embedding:

```python
self.mul_emb(
    self.embedding(x),
    math.sqrt(self.model_dims)
)
```

This performs:

```python
embedding * sqrt(768)
```

---

### Why Scale?

This follows the classic transformer formulation.

Conceptually:

```text
Embeddings
        ↓
Scale By √D
        ↓
Transformer
```

where:

```text
D = Model Dimension
```

In VoiceDM:

```text
D = 768
```

so:

```text
Scale ≈ 27.71
```

---

## Shape After Scaling

Still:

```python
[B,T,768]
```

Only values change.

Shape remains identical.

## Step 3 - Transformer Encoder

Next:

```python
h = self.transformer(
    h,
    mask=mask
)
```

This is the transformer stack we previously studied.

Configuration:

```python
12 Layers
6 Attention Heads
768 Hidden Dimension
3072 FFN Dimension
RoPE
RMSNorm
```

Conceptually:

```text
Embeddings
      ↓
Transformer Layer 1
      ↓
Transformer Layer 2
      ↓
...
      ↓
Transformer Layer 12
      ↓
Contextualized Features
```

---

## What Does The Transformer Learn?

Consider:

```text
The bank is closed.
```

versus:

```text
I sat on the river bank.
```

The same token:

```text
bank
```

has different meanings depending on surrounding words.

Self-attention allows each token to observe:

```text
Previous Tokens
Current Tokens
Future Tokens
```

and build a contextual representation.

## Mental Model

Think of TextEncoder as:

```text
Tokens
   ↓

Word Vectors
   ↓

Transformer Understanding
   ↓

Text Features
```

Its job is not to generate audio.

Its job is to transform raw text into a representation that captures meaning and can later be fused with:

```text
Speaker Information
+
Audio Context
```

inside the MetaEncoder.

---

## High-Level Architecture

```text
Token IDs [B,256]
          ↓

Embedding Layer
          ↓

Scale By √768
          ↓

Transformer Encoder x 12
          ↓

LayerNorm
          ↓

Text Features [B,256,768]
```

---

## Key Takeaways

- TextEncoder consumes token IDs, not embeddings.
- The embedding layer converts tokens into 768-dimensional vectors.
- Embeddings are scaled by √768 before entering the transformer.
- A 12-layer transformer encoder processes the sequence.
- RoPE provides positional information inside attention.
- Self-attention enables contextual understanding of text.
- The output is a contextualized text representation of shape `[B,T,768]`.
- No audio generation occurs inside TextEncoder.
