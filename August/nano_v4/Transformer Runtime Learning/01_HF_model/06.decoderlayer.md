# Gemma4 Text Decoder Layer

Input:
    hidden_states      [B, S, 1536]
    per_layer_input    [B, S, 256]
    position_embeddings
    attention_mask
    past_key_values

Flow:

1. residual = hidden_states

2. Attention path:
    hidden_states
        → input_layernorm
        → self_attn
        → post_attention_layernorm
        → add(residual)

3. Feed-forward path:
    residual = hidden_states
    hidden_states
        → pre_feedforward_layernorm
        → MLP
        → post_feedforward_layernorm
        → add(residual)

4. Gemma4 PLE path:
    residual = hidden_states
    hidden_states
        → Linear(1536 → 256)
        → activation
        → multiply(per_layer_input)
        → Linear(256 → 1536)
        → RMSNorm
        → add(residual)

5. Final:
    hidden_states
        → multiply(layer_scalar)
        → output

Current config:
    hidden_size = 1536
    intermediate_size = 6144
    hidden_size_per_layer_input = 256
    enable_moe_block = False
    num_hidden_layers = 35

Important:
    - Attention and MLP are standard Transformer concepts,
      but their exact Gemma4 implementation must be inspected.
    - PLE is an additional Gemma4-specific path.
    - MoE code exists but is inactive for this configuration.
    - Add/Mul/Linear wrappers may be deployment/quantization
      representations of ordinary mathematical operations.
